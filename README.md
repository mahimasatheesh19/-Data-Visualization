# -Data-Visualization
 Data Visualization using Python
1. Loaded dataset "Taxis" from using Seaborn.
2. Checked missing values and identified columns containing missing data. Imputed numerical columns using Median and categorical column using Mode.
3. * Visualized taxi fare over time using Line chart.
   * Created a Bar chart for the total fare by pickup borough.
   * Represented the distribution of trips by payment method using Pie chart.
   * Displayed the distribution of distance using Histogram and customized the number of bins.
   * Visualized the distribution of tip amounts for each pickup borough using Box plot.
   These visualization are created using Matplotlib.
4. Visualizations using Seaborn
   * Created a Count plot to visualize the number of trips in each pickup borough.
   * Displayed the relationship between distance and fare using Scatter plot with different color representing pickup boroughs.
   * Visualized the correlation between numerical variables distance, fare, tip, tolls, and total by Heatmap.
   * Created a Pair plot to visualize the pairwise relationships between distance, fare, tip and total.
   * Showed the distribution of fare for each payment method using Violin plot.
